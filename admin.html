Entrar

Para guardar cambios este panel necesita una clave de acceso al repositorio de la web (un “token” de GitHub). Se pega una sola vez y queda guardada solo en este navegador.

¿Cómo consigo el token?
  1. Entra a GitHub con una cuenta que tenga permiso de escritura en el repositorio.
  2. Ve a Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. En “Repository access” elige solo el repositorio de Mexperimenta.
  4. En “Permissions → Repository permissions” pon Contents: Read and write.
  5. Copia el token (empieza por github_pat_) y pégalo arriba. Nunca lo compartas.
